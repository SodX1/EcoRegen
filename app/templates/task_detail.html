Оригинальное изображение без предварительной обработки. Используется как эталон для визуального сравнения и валидации результатов анализа.
NDVI (Normalized Difference Vegetation Index) — нормализованный вегетационный индекс $(NIR - Red)/(NIR + Red)$. Применяется для оценки фотосинтетической активности и биомассы растительности, а также для выявления деградации покрова.
HSV‑анализ переводит изображение в пространство оттенок–насыщенность–яркость и выполняет пороговую фильтрацию по заданным диапазонам. Используется для сегментации по спектральным признакам и выделения тематических классов.
Сегментация — пиксельная классификация, формирующая маски объектов по модели (например, YOLO/Mask R‑CNN). Позволяет локализовать области интереса и оценивать их площадь и форму.
